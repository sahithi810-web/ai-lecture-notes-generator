# AI-Powered Real-Time Lecture Analysis and Personalized Study Notes Generator

## 📌 Project Overview

The AI-Powered Real-Time Lecture Analysis and Personalized Study Notes Generator is a Python-based application that helps students generate concise study notes from lecture content. The system analyzes lecture text, identifies important information, and creates personalized notes for quick revision and effective learning.

This project reduces manual note-taking effort and helps students focus on understanding concepts during lectures.

---

## 🎯 Objectives

- Analyze lecture content automatically.
- Extract important concepts and topics.
- Generate personalized study notes.
- Save generated notes for future reference.
- Improve learning efficiency and revision.

---

## ✨ Features

- Lecture Content Analysis
- Important Topic Extraction
- Automated Study Notes Generation

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/sahithi810-web/ai-lecture-notes-generator.git
cd ai-lecture-notes-generator
```

### Create Virtual Environment

```bash
python -m venv .venv
```

### Activate Virtual Environment

#### Windows

```bash
.venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Project

### Run Python Version

```bash
python main.py
```

### Run Streamlit Application

```bash
streamlit run app.py
```
